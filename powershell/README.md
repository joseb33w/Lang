# PowerShell

Simple PowerShell Hello World example.

## Installation on macOS

PowerShell can be installed on macOS using Homebrew (recommended method):

```bash
brew install --cask powershell
```

Or use the installation script in the root directory:
```bash
./install-powershell.sh
```

For more installation options, see: https://learn.microsoft.com/en-us/powershell/scripting/install/installing-powershell-on-macos

## Run
```powershell
pwsh hello.ps1
# or
.\hello.ps1
```
